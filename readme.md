# .PNG to .ICO Command Line Interface (CLI)

## An easy way to convert larger batches of .PNG images to .ICO favicon

After creating a .HEIC to .JPG converter, I decided to additionally solve
another problem: Creating larger batches of favicons.  

If you have a large number of .PNG image files and want to convert them to
.ICO favicons, this might be useful for you. With this Python script, it is easy
to convert entire folders of .PNG files.

## How to use

1. Download the Repository
2. Install the ```requirements.txt```
3. Run the script
4. Enter the absolute path of the directory where the files are located
5. After the script finishes, your .ico files are in the same directory as the .png files were
